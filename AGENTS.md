# Regla de entrega

- Para cualquier cambio solicitado en la aplicacion, el trabajo no se considera terminado hasta que este validado, guardado en Git, subido a GitHub, desplegado en produccion y verificado en la URL publica.
- Una vista local o un despliegue preview no cuentan como entrega final, salvo que el usuario pida expresamente no publicar.
- No publicar como archivos estaticos los datos de origen, scripts administrativos, migraciones ni secretos.
